Agentic Data-Analyst

Ask a natural-language question about Seattle's building-energy benchmarking data — ~38,000 annual filings from 3,871 buildings, 2015–2025.

The agent explores the database schema, writes and runs its own SQL, calls a trained model for predictive questions, draws a chart when a chart is the answer, and corrects itself when a query errors. Every answer shows the SQL it ran.
