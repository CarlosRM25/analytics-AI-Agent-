# Model card — Seattle high-emitter classifier

_Generated by `model/seattle_energy/train.py` on ${date} from this template

## Task

Binary classification: **`is_high_emitter`** — is a building's
`ghg_emissions_intensity` above the median for its `primary_property_type` in
that `data_year`? Normalising the label within property type and year keeps it
~balanced and forces the model past "big old building" (architecture doc §4.4).

## Data

Seattle Building Energy Benchmarking (`teqw-tu6e`), loaded by `ingest/run.py`.
Rows with a null intensity or a `demolished` flag are dropped before labelling.
Outlier rows (Tukey 3×IQR within property type × year, ~2.8%) are dropped from
**training** only.

## Headline result — and why there are two numbers

| Evaluation | HGB ROC-AUC | What it answers |
|---|--:|---|
| **Temporal** (train ≤2022 → test 2024) | **${temporal_test_auc}** | The stated task: score this year's filings from prior years |
| — 2024 buildings also seen in training (${seen_pct} of test) | ${temporal_seen_auc} | Re-scoring a building we have history for |
| — 2024 buildings new to the model (n=${new_n}) | ${temporal_new_auc} | A genuinely unseen building |
| **Building-disjoint** (random, no building on both sides) | **${disjoint_test_auc}** | Generalisation to unseen buildings, pooled years |

The temporal number is optimistic. A building's structural features
(`building_age`, `primary_property_type`, `log_gfa_total`, floors) are static and
its efficiency rank is sticky year to year, so once the model has seen a building
it mostly needs to *recognise* it, not reason about it. The building-disjoint
AUC of **~${disjoint_test_auc_2dp}** — and the small-sample temporal-new AUC of
~${temporal_new_auc_2dp} — are the honest estimate for a new building, close to
the low-0.6-to-0.7 range the M2 EDA predicted from the weak linear feature
correlations.

**In production you would retrain on all history each year and score the new
filings, so most scored buildings are "seen" — ~${temporal_test_auc_2dp} is a
fair estimate there. Treat ~${disjoint_test_auc_2dp} as the number for a building
that has never filed before.**

Baseline (LogisticRegression, temporal test): ROC-AUC ${baseline_auc}, PR-AUC
${baseline_pr} — the gap to HGB is non-linear structure and feature interactions.

## Known limitations

* **The temporal split does not isolate generalisation** (see above). This is the
  main M3 finding and it corrects an optimistic line in the architecture doc
  (§4.4) — that the split "prevents the same building's other years leaking".
* **Generalisable signal is modest** — ROC-AUC ~${disjoint_test_auc_2dp} on
  unseen buildings. The label already divides out the property-type / size / age
  structure, so what is left is hard.
* `energy_star_score` is contemporaneous with the target (both derive from the
  same 12 months of energy use). It is a minor contributor (permutation
  importance ~${energy_star_importance}) and is kept as a filing-time input, but
  it is conceptually close to the label.
* Property type is self-reported and coarse; the label is a within-cohort median
  split, so "high emitter" is relative, not an absolute environmental threshold.

## Intended use

A portfolio demonstration and the `predict` tool in the agent (M5) — "what would
the model expect a building like this to look like?". **Not** for compliance,
enforcement, or ranking real buildings. The shipped `model-${date}.joblib` is HGB
refit on all years 2015–2024 (outliers dropped); the metrics above come from
held-out evaluation.
